    02落地之后，先过关，再去喝第一杯
    1. 跟随 Arrivals / Passport control。准备护照，按现场要求接受身份查验、拍照或指纹采集。被问到旅游目的、住址、返程日期时，如实简短回答；语言不通可请求翻译协助。
    2. 检查并收好移民卡。边检发放的“小白条”与护照分辨清楚，核对姓名和日期，拍照备份，原件保留至离境；遗失或损坏，应按使馆提醒在 3 日内向当地移民部门申请补办。
    3. 取行李后再过海关。有需申报的现金或物品走申报通道；不确定时问海关。药品保留原包装、处方和必要说明，不替别人携带不明物品。入境与出境限额不是一套规则。
    4. 每次换酒店都主动确认居留登记。入住时交验所需证件，请前台确认已办理并索取回执，保留到离境。此次莫斯科 → 圣彼得堡 → 莫斯科，三段住宿都确认，不把“只住几晚”当作不用登记的理由。

    护照原件、离线往返机票、首晚酒店订单和俄文地址。三个人各留一份，不依赖其中一台手机有网。护照与材料放在随身包容易取到的夹层，别放进托运行李。

    排队与问询，按眼前的标识走

    Паспортный контроль 是护照检查；Иностранные граждане 是外国公民。先看标识，再向工作人员确认队伍。帖子里的某条“快速通道”只是当天体验；边检队伍与取行李后的海关红绿通道是两回事。

    轮到自己时按指示递交证件、摘帽或配合拍照与指纹采集。常见问题可以用离线订单辅助说明：来做什么、住哪里、待多久、何时离境。如实说明旅游及莫斯科—圣彼得堡—莫斯科的行程，不必背长答案。

    被安排补充问询时，先问清需要什么材料；语言不通可请求翻译协助。不要把他人“几分钟放行”当作自己的耗时，也别为赶酒吧与工作人员争执。确需帮助时使用本网站安全页的领事协助联系方式。

    两张纸，分别从哪里来

    移民卡 · Миграционная карта

    入境边检取得的“小白条”。离开柜台前核对，有疑问当场询问；照片备份，原件保留到出境。若未拿到纸卡，先向边检确认自己的发放方式。

    住宿登记回执

    抵达酒店后请前台办理并索取。它不是酒店预订单，也不是移民卡；三段住宿分别确认，入住和退房时都检查证件是否已归还。

    出关后，先能离开机场，再慢慢办事

    小红书实录里，网络验证、兑换柜台和现场办卡都可能额外耗时。先确认同伴与行李到齐，再处理必要现金和进城交通；办银行卡不是入境的必经步骤。不要为“更好的汇率”在 B/C 航站楼来回跑到错过接驳。

    若无法联网，就用已保存的酒店俄文地址，到正规服务台或事先安排的接机点求助。免费 Wi-Fi 也可能要求短信验证；运营商解锁是否成功因号码和当时网络而异，不以某篇帖子的成功经历作保证。

    把进站拆成四步

    1. 先到火车站入口。地铁出口、站前广场都不算已完成进站。两城都先按铁路标识找主站，完成入口及行李检查；若 Sapsan 区域另设检查，再按指示排队。
    2. 看车次，不只看终点城市。大屏上的 Поезд 是列车、Отправление 是发车、Путь 是股道、Платформа 是站台；平台编号以当天大屏为准，不照搬帖子截图。
    3. 先找到自己的车厢。票上的 Вагон 是车厢，Место 是座位。目标开车前 15–20 分钟已到正确车厢附近；站台步行和搬箱子也需要时间。护照原件按工作人员要求查验，不把“无需纸票”理解为无需证件。
    4. 放好行李再坐下。大箱按车内标识放到行李区，小包放稳，护照、手机和钱留在身边；不要占用相邻座位、车门和通道。确认全员已上车后再买餐。

    05回家那天，早点把行李送到机场

    回程航班号待核对：JD607 是杭州 → 莫斯科；公开航班资料中的莫斯科 → 杭州对应 JD608。暂不把“往返都是 JD607”写成已确认事实。请对照回程机票；此处保留原表 22:00 → 次日 11:50 的时刻。

    JD608 航线参考（第三方）↗首都航空：核对订单与航班 ↗

    10.6 的 22:00 航班：建议 15:45–16:00 从酒店带齐行李出发，目标 17:30–18:00 到正确航站楼；以当天导航与航司要求继续提前。上午郊外教堂、下午市场和取行李，不能全部按最顺利情况安排；若延误，先舍去市场。不要等到 18 点才从市区出发。

    1. 出门前：查实际承运航司的航班状态、机场代码、航站楼、值机/托运和登机截止时刻。若必须柜台核验证件，网上值机不能替代；延误通知也不代表可以更晚到机场。
    2. 打包时：护照、移民卡、住宿登记回执随身。充电宝与备用锂电池按航司规定随身携带，不放托运；容量、数量及标识要求查实际承运航司。液体、酒、鱼子酱等同时检查航空安检与中俄海关规定，能买到不代表能带回。
    3. 到机场：入口检查 → 值机/托运 → 按标识完成出境边检和安检 → 找登机口。以现场流程为准，先找到登机口再吃饭购物；登机口可能变更。
    4. 行李损坏或未到：在离开行李提取区前联系航空公司行李服务台，索取书面记录，保留行李牌、登机牌和照片。

    若发生临时限飞或长时间延误，优先看机场屏幕和航司柜台消息，询问改签、餐饮和住宿安排，保存通知与票据；不要仅等短信。出现警报时按工作人员引导避险。

    提前量是本行程建议；已知去程首都航空 JD607；回程编号与所购票种仍需核对，值机截止、行李额按自己的订单和承运航司规则执行。

    值机之后，也要继续留时间

    一篇 SVO 回国实录中，值机完成到进入候机区仍花了约一小时，主要耗在找路与检查队伍上。它不是平均值，但足以提醒：拿到登机牌后先完成剩余检查，别立刻去购物。按现场标识找外国公民边检通道，移民卡备好，按要求交还。

    登机牌印的是当时的登机口；进候机区后再次看大屏，并留意临时变更。分清“起飞时间”和“登机截止”，22:00 不是到登机口的时间。

    排队前，少翻几次包

    证件与登机牌放在同一随身夹层；电子设备保持能开机的电量，是否取出、脱鞋或开机按现场安检要求做。过完每一道检查，停一下确认护照、移民卡（尚未交回时）、手机和随身包都已拿回。

    如果队伍很长、离截止时间已近，拿登机牌向航司或现场工作人员说明；是否安排优先处理由他们决定。不要自行插队，也不要因为看见航班延误便离开候机区域。
